# StyleUp

StyleUp is an Expo React Native starter for organizing a wardrobe and planning outfits.

## Run the app

1. Install Node.js LTS and Expo dependencies.
2. In this folder, run `npm install`.
3. Start the development server with `npm run start`.
4. Press `i` in the Expo terminal to open the iOS simulator, or scan the QR code with Expo Go.
5. Run `npm run web -- --port 8083` to open the browser version at `http://localhost:8083`.

The app shows a five-second logo placeholder before opening the main experience. Replace the `YOUR LOGO` placeholder in `App.tsx` with your logo component or image when ready. The `assets` folder is available for image files.
